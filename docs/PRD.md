# 사이트 설계도(PRD) — 바로쓰는 AI · 조현주

작성일: 2026-10-25 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
기업 교육 담당자에게 AI·스마트폰 활용 강의를 소개하고 출강 문의를 받는 사이트

## 2. 손님
- 누가: 기업 교육 담당자 (직원 대상 교육·출강 강사를 찾는 회사)
- 어디서 알고 오나: 블로그·SNS

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 강의 주제·커리큘럼 — 어떤 내용을 몇 시간에 걸쳐 배우나
2. 강사 경력·출강 이력 — 어떤 회사·기관에서 강의해 봤나
3. 강의료·견적

## 4. 믿게 할 증거 (실제로 있는 것만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 강의 문의하기
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로)
한 페이지로 만든다.
1. 첫 화면 — 한 문장 + 버튼(강의 문의하기)
2. 강의 주제·커리큘럼 — AI 활용 강의, 스마트폰 활용 강의 (프로필의 전문 분야 기준, 세부 차시·시간은 미정)
3. 강사 소개 — 조현주 소개·소속, 자격 사항, 강의 경력(출강 이력), 저서
4. 강의료 안내 — (비워 둠)
5. 후기 자리 (비워 둠)
6. 문의 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 문의 내용 (자유롭게 — 회사명·인원·원하는 주제 등)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: (비워 둠 — 나중에 정하기로 함)
- 시간: (미정)
- 위치(출강 지역): (미정)
- 연락 방법: (미정 — 프로필에 전화·이메일·블로그가 있지만, 사이트에 공개할지는 사용자가 정한다)

## 9. 이번에 넣지 않을 것
- 블로그·칼럼
- 자료 내려받기 (강의 소개서 PDF)
- 온라인 결제
- 강의 일정 달력
- 회원가입·로그인

## 10. 첫 화면 한 문장 후보
0. AI를 배우는 것이 아니라, AI를 활용하는 힘을 만들어 드립니다. (프로필 문구)
1. 직원들이 내일부터 바로 쓰는 AI·스마트폰 활용 강의
2. 우리 회사 업무에 맞춘 AI 활용 교육, 찾아가서 강의합니다
3. AI가 어려운 직원도 따라오는 실습 중심 기업 강의

## 11. 다음에 할 것
- 강의료 안내 방식·금액 정하기
- 연락 방법 중 사이트에 공개할 것 정하기
- 기업 출강 이력이 생기면 강의 경력에 추가하기
- 실제 수강 후기 모으기
- 블로그·칼럼, 자료 내려받기, 강의 일정 달력, 온라인 결제

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 깔끔한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. (문의 저장이 '예'일 때) 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
